### Mecánica
- Una flecha indica exactamente qué movimiento debe hacer el jugador.
- **El perfil solo cambia cuando el jugador pulsa la flecha correcta.**
- Una tecla incorrecta no cambia el perfil.
- Si se acaba el tiempo tampoco cambia el perfil.
- Los errores quitan una vida, pero el mismo perfil permanece.
- Al acertar, el perfil hace una pequeña animación de swipe y recién después aparece el siguiente.
- 5 fases de velocidad.
- 3 vidas y puntaje.
- Al completar el recorrido aparece primero el perfil de GAZTi durante un momento con confeti retro; después aparece la tarjeta de victoria y el Cromo #01.

### Imágenes
Las fotos de los perfiles están en formato original.
Jessi y GAZTi también usan sus fotos originales.
El estilo retro se aplica a la interfaz y efectos, no degradando las fotos.
