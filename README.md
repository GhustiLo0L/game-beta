### Mecánica
- Aparece una flecha que indica el swipe que debe hacer Jessi.
- El jugador debe pulsar la flecha correcta.
- Si se equivoca, pierde una vida pero **el perfil NO cambia**.
- Si se acaba el tiempo, pierde una vida y **el perfil NO cambia**.
- El mismo perfil queda hasta acertar la flecha.
- Solo después de acertar aparece el siguiente perfil.
- 5 fases de velocidad.
- 3 vidas.
- Puntaje.
- Cromo #01 al encontrar a GAZTi.
