# GAZTi & JESI — La Aventura ❤️

Base de un pequeño plataformero retro hecho solamente con HTML, CSS y JavaScript.

## Probarlo localmente

Abrí `index.html` en el navegador.

## Subir a GitHub

1. Creá un repositorio nuevo.
2. Subí `index.html`, `style.css`, `game.js` y la carpeta `assets`.
3. No hace falta instalar nada.

## Publicarlo en Netlify

1. Entrá a Netlify.
2. Elegí "Add new project" / "Import an existing project".
3. Conectá GitHub.
4. Elegí este repositorio.
5. Build command: dejar vacío.
6. Publish directory: `/`
7. Deploy.

## Controles

- Flechas izquierda/derecha: mover
- Espacio o flecha arriba: saltar
- R: reiniciar
