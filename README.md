# ♥ Jessi Quest — Nivel 1

Mini juego retro/pixelado hecho en HTML, CSS y JavaScript puro. No necesita servidor, base de datos ni dependencias.

## Cómo publicarlo
1. Subí `index.html`, `README.md` y la carpeta `assets` a un repositorio de GitHub.
2. En Netlify elegí **Add new project → Import an existing project → GitHub**.
3. Seleccioná el repositorio.
4. Build command: dejar vacío.
5. Publish directory: `.`

También podés arrastrar la carpeta completa a Netlify para una publicación rápida.

## Controles
- Teclado: ↑ ↓ ← →
- Celular: botones en pantalla.

## Nivel 1
Jessi está buscando el perfil de GAZTi en Boo. Hay cinco fases de velocidad, perfiles falsos, vidas, puntaje y un Cromo #01 al completar el nivel.

Los retratos pixelados incluidos fueron generados a partir de las fotos proporcionadas para este proyecto.
